# Meow Market — интернет-магазин товаров для котов

## Тема контрольной работы №3

**«Адаптивная вёрстка и доступность многостраничного HTML/CSS-сайта»**

## Краткое описание проекта

Meow Market — это многостраничный сайт интернет-магазина, специализирующийся на товарах для котов (корм, игрушки, лежанки, аксессуары, уход). Проект включает в себя главную страницу, каталог с фильтрами, карточку товара, форму оформления заявки и страницу контактов.

## Список адаптивных решений

- Подключён отдельный файл `css/responsive.css` на всех страницах после основного файла стилей.
- Используются **медиазапросы** (подход Desktop First: базовые стили для широких экранов адаптируются под планшеты и мобильные устройства).
- **Навигация:** на ширине ≤1023px появляется бургер-меню с корректным управлением `aria-expanded`.
- **Сетка карточек:** на планшете — 2 колонки, на мобильном — 1 колонка (CSS Grid).
- **Каталог и фильтры:** на планшете и мобильном фильтры перестраиваются в колонку, `position: sticky` отключается.
- **Таблица характеристик:** базовая горизонтальная прокрутка через `.table-wrapper`, а на мобильном (≤767px) — карточное представление (скрывается `thead`, строки становятся блоками).
- **Форма заявки:** на мобильном экране поля выстраиваются в одну колонку, кнопка занимает всю ширину.
- **Responsive images:** используется правило `max-width: 100%`, тег `<picture>` для фонового изображения (WebP/GIF), а также явные атрибуты `width` и `height` для предотвращения сдвигов макета (Layout Shift).
- **Отсутствие горизонтального скролла:** глобально ограничен через `overflow-x: hidden`, широкие элементы обернуты в контейнеры.

## Список исправлений доступности

- Добавлена ссылка **skip-link** («Перейти к основному содержимому») с видимым фокусом.
- Обеспечен **видимый фокус** (`:focus-visible`) для всех интерактивных элементов.
- Проверено наличие атрибута **`label`** у всех полей формы.
- Проверены **`alt`**-описания у изображений (логотип, фото кота, декоративные элементы).
- Модальное окно доступно с клавиатуры: закрывается по **Esc**, клику на оверлей и кнопке.
- Добавлены **`aria-label`** для кнопок без текста (точки-переключатели слайдера).
- Увеличены области нажатия (**Touch targets**) для мелких интерактивных элементов.
- Исправлен **контраст текста** (цвет `--color-muted` затемнен для соответствия WCAG).
- Использована семантическая разметка (`header`, `nav`, `main`, `section`, `article`, `aside`, `footer`), на каждой странице есть только один `h1`.

## Информация о Lighthouse-проверке

Проверка выполнена в режиме **Mobile**. Оценки по категории **Accessibility**:

- `index.html` — **93/100**
- `catalog.html` — **100/100**
- `order.html` — **96/100**
- `contacts.html` — **91/100**

_(Снижение оценки Performance на главной странице до 70/100 обусловлено использованием тяжелых GIF-анимаций и внешних шрифтов, что допустимо для учебного проекта)._

Скриншоты отчетов сохранены в папке `lighthouse/`.
